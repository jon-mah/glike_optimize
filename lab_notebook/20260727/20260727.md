# 20260727: Standards for joint multi-sample variant calling

* Current best practice for human germline variant calling is **joint genotyping** from per-sample gVCFs, rather than simply merging VCFs.
    * Each sample is processed independently using `HaplotypeCaller -ERC GVCF`.
    * The resulting gVCFs contain genotype likelihoods and reference-confidence information, **not** finalized genotype calls.
    * Joint genotyping uses information from all samples simultaneously to determine:
        * Whether a site is polymorphic.
        * Genotype likelihoods.
        * Allele frequencies.
        * Improved genotype quality, particularly for rare variants.
* Recommended GATK workflow:
    1. `BAM/CRAM`
    2. `HaplotypeCaller` (-ERC GVCF)
    ```
    sample1.g.vcf.gz
    sample2.g.vcf.gz
    ...
    ```
    3. `GenomicsDBImport`
    4. `GenotypeGVCFs`
    5. Multi-sample VCF
    6. `VQSR` (or hard filtering)
    7. Analysis-ready cohort VCF 
* For our cohort:
    * **546 gVCFs (500 Native Hawaiian individuals)** falls well within the recommended range for `GenomicsDBImport`.
      * [Source]()
    * `CombineGVCFs` is generally intended only for relatively small cohorts and is no longer the preferred scalable solution.
* Example `bash` commands:
    ```bash
    gatk GenomicsDBImport \
        --sample-name-map cohort.sample_map \
        --genomicsdb-workspace-path cohort_db \
        -L chr1
    ```
    ```bash
    gatk GenotypeGVCFs \
        -R reference.fa \
        -V gendb://cohort_db \
        -O cohort.vcf.gz
    ```
* GATK joint-calling workflow is compatible with downstream tools including `PLINK`, `bcftools`, `Beagle`, `SHAPEIT5`, `GLIMPSE`, `Eagle`, and **imputation reference panel generation**.

* Alternative pipelines:
    * Solution 1: **DeepVariant + GLnexus**
        * Increasingly common for large whole-genome sequencing projects.
        * Often matches or exceeds GATK SNP/indel accuracy while scaling efficiently.
    * Solution 2: **Illumina DRAGEN**
        * Hardware-accelerated joint variant calling used in many clinical sequencing pipelines.
    * Nonsolution: **bcftools merge**
        * **Not** equivalent to joint genotyping.
        * Only merges existing genotype calls without recomputing genotype likelihoods across individuals.
